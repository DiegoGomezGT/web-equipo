# Editor de Texto - Web Equipo

Un editor de texto web con funcionalidades completas de edición, desarrollado para el equipo web.

## Características

### Menú de Editar
- **Deshacer/Rehacer**: Permite deshacer y rehacer cambios en el texto
- **Cortar/Copiar/Pegar**: Operaciones básicas de edición de texto con soporte para portapapeles
- **Seleccionar Todo**: Selecciona todo el contenido del editor
- **Buscar**: Función de búsqueda de texto con modal interactivo
- **Reemplazar**: Función de buscar y reemplazar con opciones de reemplazo individual o masivo

### Características Adicionales
- **Barra de Herramientas**: Acceso rápido a funciones comunes de edición
- **Contador de Palabras y Caracteres**: Muestra estadísticas en tiempo real del texto
- **Formato de Texto**: Opciones básicas de formato (negrita, cursiva, subrayado)
- **Operaciones de Archivo**: Nuevo, abrir y guardar documentos
- **Diseño Responsivo**: Funciona en dispositivos móviles y de escritorio
- **Accesibilidad**: Soporte para navegación por teclado y lectores de pantalla

## Uso

1. Abrir `index.html` en un navegador web
2. Usar el menú "Editar" para acceder a todas las funciones de edición
3. Escribir texto en el área de edición
4. Usar los atajos de teclado para operaciones rápidas:
   - `Ctrl+Z`: Deshacer
   - `Ctrl+Y` o `Ctrl+Shift+Z`: Rehacer
   - `Ctrl+X`: Cortar
   - `Ctrl+C`: Copiar
   - `Ctrl+V`: Pegar
   - `Ctrl+A`: Seleccionar todo
   - `Ctrl+F`: Buscar
   - `Ctrl+H`: Reemplazar

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica del editor
- **CSS3**: Estilos modernos y diseño responsivo
- **JavaScript**: Funcionalidad interactiva y manejo de eventos
- **APIs del Navegador**: Clipboard API para operaciones de portapapeles

## Estructura de Archivos

- `index.html`: Estructura HTML principal
- `styles.css`: Estilos CSS del editor
- `script.js`: Lógica JavaScript y funcionalidades

## Compatibilidad

Compatible con navegadores modernos que soportan:
- ES6+
- Clipboard API
- HTML5
- CSS3
